# Notes for AI coding agents

This is a Remotion project generated by Tasjeel, a Mac screen recorder, from one recording. The user wants help making the video look better: captions, titles, cards, layouts, extra scenes.

## Layout

- `public/recording.mp4` is the recording, already edited in Tasjeel (cuts, zooms, wallpaper, camera overlay). H.264 with sound. Do not re-encode or replace it.
- `src/recording.json` is data about that video, typed by `src/types.ts`: `title`, `language`, `rightToLeft`, `fps`, `width`, `height`, `durationInSeconds`, `captions`, `chapters`, `notes`. Tasjeel overwrites this file and the video when the user exports again, so never edit them by hand and never hard-code values copied from them: read them from the `recording` prop.
- `src/Root.tsx` registers one composition, `Recording`, sized and timed from the data.
- `src/Video.tsx` is the composition: the video, then overlay layers in drawing order.
- `src/components/` holds the overlays. `src/settings.ts` holds the switches a non-programmer may change.
- `src/lib/time.ts` converts seconds to frames.

## Rules that matter here

- Every time in `recording.json` is in **seconds**. Convert with `toFrames(seconds, fps)` or `frame / fps`.
- Captions are whole lines with a start and an end. There are no word timings; `Captions.tsx` estimates them from letter counts. `speaker` is `"You"`, `"Others"` or `null`.
- `notes` and `chapters` come from an AI summary and may be empty or `null`. Handle that.
- When `rightToLeft` is true (Arabic, Hebrew) set `dir="rtl"` on text and mirror horizontal motion.
- Size everything from the composition's width and height, never fixed pixels: recordings come in any resolution and aspect ratio.
- The fonts are system fonts so that nothing is downloaded. If you add a web font, use `@remotion/google-fonts` or `@remotion/fonts` at the same version as `remotion`.
- All Remotion packages must stay on exactly the same version. Use `npx remotion upgrade` to change it.
- Animate only with `useCurrentFrame()`, `interpolate()` and `spring()`. CSS transitions and animations do not render.

Remotion's own skills are in `.agents/skills` once the user has run `Start.command` (or `npm run skills`). Use them, starting with `remotion-best-practices`.

## Commands

- `npm run dev` opens Remotion Studio.
- `npm run typecheck` must pass before you call a change done.
- `npm run still` renders one frame to `out/frame.png`; use `npx remotion still Recording out/x.png --frame=N` to look at a specific moment.
- `npm run render` renders `out/video.mp4`.
