# Notes for AI coding agents

This is a Remotion project generated by Tasjeel from a storyboard. It is a short marketing video made of scenes, rendered in three sizes from the same code. The user wants help with how scenes look and move.

## Layout

- `src/storyboard.json` is the video as data, typed by `src/types.ts`: `brand` (colours, logo, font), `formats`, and `scenes`. Tasjeel rewrites this file and `public/media/` every time the user rebuilds from their storyboard, so **never edit them and never hard-code values copied from them**. If the user wants different words, pictures, order or timing, tell them to change their storyboard file and rebuild; change code only for how things look and move.
- `src/Root.tsx` registers three compositions, `Wide` (1920x1080), `Square` (1080x1080) and `Tall` (1080x1920). All three play `src/Video.tsx`.
- `src/Video.tsx` puts the scenes in a `<Series>` and wraps each in `SceneFrame` (padding, text direction, corner logo, fade out).
- `src/scenes/` has one component per scene type: `hook`, `screen`, `feature`, `quote`, `numbers`, `cta`.
- A scene may have narration: `voice` is its sound (an MP3 in `public/media/`), `words` the timing of each word, `say` the text. `Narration` in `src/Video.tsx` plays the voice and `src/components/Spoken.tsx` draws the words as captions that follow it. A video built without a voiceover has `voice: null` and plays silent.
- `src/lib/layout.ts` has `useLayout()` and `fitText()`. `src/lib/motion.ts` has `useEnter()`, `rise()` and `useExit()`.

## Rules that matter here

- **Every scene must work in all three sizes.** Size everything with `u` from `useLayout()` (one hundredth of the short side), never fixed pixels, and use `sideBySide` and `tall` to change the arrangement. Check a change in Wide, Square and Tall before calling it done.
- Take colours and the font from `brand` (`src/storyboard.ts`). Do not introduce colours of your own.
- Optional fields are `null` or empty arrays when absent. Handle that.
- When `storyboard.rightToLeft` is true the scene frame sets `dir="rtl"`. Use logical CSS (`insetInlineStart`, `textAlign: "start"`) so layouts mirror by themselves, and keep `dir="ltr"` on figures and web addresses.
- Screen clips are already trimmed and are H.264. Do not add `trimBefore`.
- Animate only with `useCurrentFrame()`, `interpolate()` and `spring()`. CSS transitions and animations do not render.
- Inside a scene, frame 0 is the scene's first frame and `useVideoConfig().durationInFrames` is the scene's own length.
- To add a new kind of scene: add its type to `src/types.ts`, a component in `src/scenes/`, and a case in `render()` in `src/Video.tsx`. Tasjeel's own checker only accepts the six built-in types, so tell the user a new type has to be added to Tasjeel as well.
- All Remotion packages must stay on exactly the same version. Use `npx remotion upgrade` to change it.

Remotion's own skills are in `.agents/skills` once the user has run `Start.command` (or `npm run skills`). Use them, starting with `remotion-best-practices`.

## Commands

- `npm run dev` opens Remotion Studio.
- `npm run typecheck` must pass before you call a change done.
- `npx remotion still Wide out/x.png --frame=N` (also `Square`, `Tall`) renders one frame to look at.
- `npm run render` renders every size listed in the storyboard into `out/`.
